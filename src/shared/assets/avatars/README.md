## លក្ខណៈបច្ចេកទេសដែលណែនាំ

| ចំណុច | តម្លៃណែនាំ |
|---|---|
| ទម្រង់ឯកសារ | `.jpg` |
| ទំហំ | 200 × 200 ភីកសែល (ការេ) |
| ទំហំឯកសារ | ក្រោម 40 KB |
| ការដាក់មុខ | នៅចំកណ្តាល |

## បើរូបភាពមិនទាន់មាន

ប្រព័ន្ធបង្ហាញ **អក្សរកាត់ឈ្មោះ** ក្នុងរង្វង់ពណ៌ខៀវជំនួស ដូច្នេះក្បាលទំព័រ
នៅតែស្អាតដដែល ហើយមិនដែលបង្ហាញរូបភាពខូចឡើយ។
