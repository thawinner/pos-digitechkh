# រូបភាពទំនិញ (Product Images)

ដាក់រូបថតទំនិញនៅទីនេះ ដោយដាក់ឈ្មោះឯកសារតាម **លេខបាកូដ (SKU)** របស់ទំនិញនីមួយៗ។

> ⚠️ **សំខាន់**៖ ឈ្មោះឯកសារត្រូវតែជាលេខបាកូដពិតប្រាកដ។ បើដាក់លេខផ្សេង
> (ឧទាហរណ៍ដាក់តាមលំដាប់ 0005, 0006) រូបភាពនឹង**មិនបង្ហាញទេ** ព្រោះប្រព័ន្ធ
> រកទំនិញតាមលេខបាកូដ។ បុព្វបទខុសគ្នាតាមប្រភេទទំនិញ។

## លក្ខណៈបច្ចេកទេសដែលណែនាំ

| ចំណុច | តម្លៃណែនាំ |
|---|---|
| ទម្រង់ឯកសារ | `.png` (ផ្ទៃខាងក្រោយថ្លា) |
| ទំហំ | 400 × 400 ភីកសែល (**ការេ**) |
| ទំហំឯកសារ | ក្រោម 300 KB ក្នុងមួយរូប |
| ផ្ទៃខាងក្រោយ | **ថ្លា** — ព្រោះផ្ទាំងគិតលុយមានផ្ទៃងងឹត |
| ទីតាំងទំនិញ | នៅចំកណ្តាល មានគម្លាតជុំវិញបន្តិច |

ប្រព័ន្ធប្រើ `object-contain` ដូច្នេះរូបភាពបង្ហាញទាំងមូល **មិនត្រូវកាត់ឡើយ**។

## បើរូបភាពមិនទាន់មាន

ប្រព័ន្ធបង្ហាញ **រូបតំណាងជំនួស** ដោយស្វ័យប្រវត្តិ ដូច្នេះផ្ទាំងគិតលុយនៅតែដំណើរការធម្មតា។
គ្រាន់តែដាក់ឯកសាររូបភាពចូល នោះវាបង្ហាញភ្លាមៗ ដោយមិនចាំបាច់កែកូដឡើយ។

## ការដកផ្ទៃខាងក្រោយចេញ

បើរូបថតដើមមានផ្ទៃសសុទ្ធ សូមដកវាចេញមុននឹងដាក់ចូល។ វិធីសាស្ត្រដែលប្រើគឺ
flood-fill ចាប់ពីគែមរូប ដូច្នេះមានតែតំបន់សដែលភ្ជាប់ទៅគែមប៉ុណ្ណោះត្រូវដក —
ផ្នែកសនៅខាងក្នុងទំនិញ (ស្លាកកាហ្វេ ក្រែមនំខេក) នៅដដែល។
បន្ទាប់មកស្រមោលស្រាលៗត្រូវកាត់ចេញបន្តិចម្តងៗពីគែមចូលក្នុង។

ប្រសិនបើរូបថតមានផ្ទៃថ្លារួចហើយ សូមរក្សាវាទុកដដែល។

After adding `<sku>.png` here, add the SKU to `PRODUCT_PHOTOS` in `src/shared/scripts/data.js`. Products not in that list show a flat colour tile with a short name and no image request.
